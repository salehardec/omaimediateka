# Omaimediateka

> English version: [README.md](README.md)

Бар-виджет Omarchy Shell (Quickshell) для **просмотра** фото и видео с
iPhone, подключённого **USB-кабелем**: кнопка в центре бара, попап по
центру экрана со сеткой превью из `DCIM` и полноэкранным просмотром.

> Этап 1 — только чтение. Плагин ничего не импортирует на компьютер и не
> удаляет с телефона, не трогает музыку, контакты и прочие файлы.

## Возможности

- **Кнопка в баре** — пилюля `iPhone · N` (N = число фото и видео).
- **Сетка** — превью фото и видео из всех папок `DCIM` (`100APPLE`,
  `101APPLE`, …), ленивая генерация миниатюр, кэш на диске.
- **Полноэкранный просмотр** — выбранный кадр почти на весь экран, подпись
  (имя, дата, размер), навигация стрелками; для видео — воспроизведение
  (если доступен QtMultimedia).
- **Сортировка** — по умолчанию новые сверху (по номерам Apple), можно
  переключить на «сначала старые».
- **Фильтр** — живой поиск по имени файла и папке.
- **Экспорт** (на телефоне ничего не меняется): сохранение оригинала в
  `~/Pictures/iPhone` (`Ctrl+S`) или в выбранную папку (`Ctrl+Shift+S`);
  занятые имена получают суффикс ` (1)`, ` (2)` вместо перезаписи. `Ctrl+C`
  кладёт фото в буфер как `image/png` (HEIC декодируется `heif-convert`),
  а видео — текстовым путём.
- **Выбор нескольких**: `Space`, чекбокс или `Ctrl`+клик отмечают ячейки,
  `Ctrl+A` — все видимые; кнопки экспорта работают со всем выделением.
- **Состояния** — «iPhone не подключён», «нужно доверие», «нет gvfs-afc»
  и т.п. с понятной инструкцией вместо пустого экрана.

## Требования к системе

Плагин сам систему не меняет. Один раз выполните (нужен `sudo`):

```bash
sudo pacman -S gvfs-afc
sudo systemctl start usbmuxd
```

`usbmuxd.service` статическая: её поднимает udev при подключении iPhone,
поэтому `enable` не требуется — достаточно подключить кабель. Затем
разблокируйте iPhone и нажмите **«Доверять этому компьютеру»**.

Проверка:

```bash
idevice_id -l                       # должен показать UDID
idevicepair -u <UDID> validate      # SUCCESS: Validated pairing
ls "$XDG_RUNTIME_DIR"/gvfs/afc:host=*   # появится DCIM/
```

Используемые пакеты: `libimobiledevice`, `libusbmuxd`, `usbmuxd`,
`libheif` (`heif-convert`), `ffmpeg`/`ffprobe`, `qt6-multimedia-ffmpeg`,
`wl-clipboard` (`wl-copy`) — для копирования в буфер; `zenity` или
`kdialog` (необязательно) — для «Сохранить как».

## Установка

```bash
./install.sh
```

Затем добавьте виджет в центр бара — `~/.config/omarchy/shell.json`,
секция `bar.layout.center`:

```json
{ "id": "omaimediateka" }
```

И перезапустите шелл:

```bash
omarchy restart shell
```

Вручную — скопировать файлы плагина в
`~/.config/omarchy/plugins/omaimediateka/` (папка создаётся по `id` из
`manifest.json`) и сделать `bin/oma-mediateka` исполняемым.

Удаление: `./install.sh --uninstall`.

## Использование

| Действие | Как |
|---|---|
| Открыть/закрыть попап | клик по пилюле в баре |
| Движение по сетке | `← → ↑ ↓` или `hjkl` |
| Открыть просмотр | `Enter`, `Space` или клик |
| Фильтр | начните печатать; `Esc` в поле очищает |
| Сортировка | кнопка «Сначала новые/старые» |
| Предыдущий/следующий в просмотре | `← →` или кнопки по краям |
| Видео: играть/пауза | `p`, `Space` или кнопка «Играть» |
| Сохранить в `~/Pictures/iPhone` | `Ctrl+S` или кнопка «Сохранить» |
| Сохранить как (выбор папки) | `Ctrl+Shift+S` или «Сохранить как» |
| Копировать в буфер | `Ctrl+C` — фото картинкой, видео путём |
| Выбрать/снять ячейку | `Space`, чекбокс или `Ctrl`+клик |
| Выбрать всё видимое | `Ctrl+A` |
| Снять выделение | `Esc` или кнопка «Снять выбор» |
| Назад к сетке | `Esc` |
| Закрыть попап | `Esc` (из сетки) |

## Как это работает

- Доступ к `DCIM` — через **gvfs-afc**: `gio mount afc://<UDID>/` и путь
  `$XDG_RUNTIME_DIR/gvfs/afc:host=<UDID>/`. `gvfsd-fuse` поднимает
  пользовательская сессия, root не нужен, при отключении кабеля путь
  исчезает сам.
- `bin/oma-mediateka` — единственное место, знающее о бэкенде:
  - `status` — определяет устройство/доверие/монтирование (JSON);
  - `list <dcim>` — один проход `find` по медиафайлам (TSV);
  - `thumb <src> <dst> <kind> [thumb|preview]` — превью в кэш;
  - `meta <src>` — длительность/размеры видео;
  - `names <dir>` / `copy <src> <dst>` — экспорт: список имён и копирование
    оригинала (без перезаписи; суффикс ` (1)`, ` (2)` добавляет интерфейс);
  - `clip-image <src>` / `clip-text <text>` — буфер обмена через `wl-copy`;
  - `pick-dir [start]` — выбор папки (`zenity`, иначе `kdialog`).
- Превью: JPEG/PNG/WebP — `ffmpeg`; **HEIC/HEIF** — `heif-convert`
  (ffmpeg в системе без HEIF); видео — кадр через `ffmpeg`.
- Кэш: `~/.cache/omaimediateka/thumbs/` и `.../previews/`; миниатюры
  генерируются лениво по мере появления ячеек на экране, по одной за раз,
  и не пересчитываются без изменения файла (ключ включает `mtime`+размер).
- Состояние опрашивается раз в 2.5 с при открытом попапе и раз в 6 с при
  закрытом; отключение телефона сразу переводит интерфейс в «не подключён».

Дизайн-спека: [`docs/superpowers/specs/2026-10-01-iphone-media-plugin-design.md`](docs/superpowers/specs/2026-10-01-iphone-media-plugin-design.md).

## Ограничения

- **Только чтение** с телефона: ничего не удаляется и не меняется на iPhone,
  экспорт лишь копирует оригиналы наружу.
- Экспорт **никогда не перезаписывает**: занятое имя получает суффикс
  ` (1)`, ` (2)`, …
- Сортировка — по номерам Apple, а не по EXIF-дате.
- **Живые фото** показываются как два элемента (HEIC и MOV).
- Один iPhone одновременно (берётся первый найденный).
- `ifuse` не используется; бэкенд изолирован в `bin/oma-mediateka`.
